# Runbook: product-led ad library run

Run from `Desktop\minimalist-ad-tool`. `<run>` is a run id such as `2026-10-03-pilot`. Steps marked **[agent]** are judgement steps done by a Claude agent with the named prompt; everything else is code.

| # | Step | Command / prompt | Check before moving on |
|---|---|---|---|
| 0 | Refresh inputs (as needed) | `node scripts/build_brand_pack.js` · `node scripts/build_trends.js` · winners: `research/winners.json` (winner agent) · the brand's own top-running statics: `node scripts/collect_own_top_ads.js` (from a browser capture) → `node scripts/make_top_runner_gallery.js`. **Meta evidence is statics only** (image and carousel), for competitors and the brand: video ads are ignored by the code | Winner tags present; trend file date |
| 0b | Trending now (**weekly, automatic**: `scripts/schedule_weekly.ps1` sets it up; by hand: `node scripts/adlib_weekly.js`) | The script reads each competitor's active ads in the Meta Ad Library (hidden browser, throwaway profile, statics only), marks every recent static live or stopped (`research/competitor_status_<date>.json`), saves new launches (`research/competitor_ads_weekly.json`; sorted into formats by `prompts/trend_tagger.md` when a Claude key is set, otherwise listed as untagged), rebuilds `research/trending.json` + `.md` (formats that ≥ 2 brands launched in the last 60 days and still run) and the gallery, and writes `research/adlib_weekly/<date>.md`, which names any trending format not yet recreated. Recreate each with a PAIRS entry `{"handle", "template_id", "angle": "trend", "trend": true}` (blends those recent ads instead of the 30+-day winners); the gallery shows them in "Trending now" | Every trend has ≥ 2 brands; each recreation names its references |
| 1 | Pick formats per product (archetype skill) | `node pipeline/00_product_run.js <run> <formats-per-product> <handle> …` | Shortlist varied across families; risk levels sensible |
| 2 | **[agent]** Write briefs | `prompts/pipeline_brief_writer.md` on `brief_inputs/*.md` → `briefs_draft/*.json` | Every line cited |
| 3 | Gate | `node pipeline/05_compliance.js <run>` | Count of `needs_retry` |
| 4 | **[agent]** Retry loop (≤3 rounds) | `node pipeline/05b_retry.js <run> prepare` → the writer rewrites from `retry_inputs/*.roundN.md` → step 3 again | Flags removed or replaced, never reworded |
| 5 | **[agent]** AI judge (stand-in until an API key exists) | `judge_prompts/` → `judge/<id>.json`, then step 3 again | New findings → step 4 |
| 6 | Keep best versions | `node pipeline/05b_retry.js <run> finalize` | No brief dropped |
| 6b | **[agent]** Style fit (house text budget from the brand's own top-running statics) | `node scripts/style_check.js <run>` → for flagged briefs, `prompts/style_editor.md` → `<run>/style_edits.json` → `node scripts/apply_style_edits.js <run>` (code refuses any new word, citation problem or rule hit; replaced lines move to the caption) | Style check exits 0 |
| 7 | **[agent]** Image prompt director (optional since 2026-10-04: the minimal look draws no scene backgrounds) | `node pipeline/06b_director_inputs.js <run>` → `prompts/image_prompt_director.md` → `director/<id>.json` | `node pipeline/06c_prompts.js <run>` re-checks every prompt |
| 8 | Image step (only for formats with a person or frames) | `node pipeline/07b_image_jobs.js <run>` lists every image still needed: **person** (brief `person_prompt`) and **frames** (brief `frames_prompt`; one image with 2–3 panels), plus a background if the director ran. `<run>/casting_overrides.json` recasts people (balanced Indian women and men). Generate in ChatGPT (browser, the user logs in) or via the API (`lib/image_api.js`), then `python scripts/split_frames.py <run>`. **Any model (person, hands, skin frames) makes the ad Severe** (user rule 2026-10-04): kept for review, not exportable; `node scripts/apply_model_risk.js` applies the rule to older runs | Look at every image: no product, no text; people natural, AI mark expected |
| 9 | Compose + re-check | `node pipeline/08_compose.js <run>` → `finals/<id>.svg` (clean cut-out + shadow when the asset library has one), then `node pipeline/08b_png.js <run>` (headless Edge) → `finals/<id>.png` | Look at every final PNG |
| 10 | Save to the ad library | `node pipeline/09_library.js <run>` → `ad_library/<product>/<format>/` with `<id>.png` + `<id>.md` description; then `node scripts/make_library_gallery.js` → `ad_library/index.html` (review gallery) | Description complete; review every ad in the gallery |
