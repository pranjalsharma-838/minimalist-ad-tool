# Minimalist Ad Creative Tool (prototype)

Work in progress. Two surfaces:

- **Generate** — paste a beminimalist.co product URL, get a composed 1080×1080 ad built from the real product photo and only the facts on that product page.
- **Score** — paste any ad (ours or not) and get a pre-review report: flagged spans, severity, the rule each flag comes from, a suggested fix, and a verdict.

Setup, design decisions and limitations will be filled in as the build progresses.
